#  🚘⛈️ RoadGuard 

**RoadGuard** is a proposed lightweight road perception system for object detection and distance estimation under adverse weather and lighting conditions, with future edge deployment in mind.

## Project Overview

The project aims to develop a software prototype that identifies road objects and estimates their distances using recorded driving data. It will investigate LiDAR-based and RGB-camera-based approaches, then select one based on dataset availability and computational feasibility.

## Planned Features

- Road object detection and distance estimation
- Recorded dataset playback and visualization
- Evaluation under selected adverse weather and lighting conditions
- Dashboard for viewing detections and distance estimates
- Structured storage of predictions and experiment results
- Performance evaluation for accuracy, processing speed, and memory usage

## Proposed Technologies

Python, PyTorch, and suitable computer vision tools. The final models, datasets, and dashboard technologies will be selected during the feasibility stage.

## Project Status

**Planning stage** — initial repository setup. Development and implementation are upcoming.

## Scope

The final prototype will demonstrate one selected perception approach using existing recorded datasets on a computer. Physical sensor integration and deployment on an edge device are outside the initial scope.
